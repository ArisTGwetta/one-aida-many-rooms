## Repair and contracts

Ordinary Chat supplies `context.memoryReview.version: 1`. Its awake response
requires a bound evaluation (review ID/scope/source coverage; five assessed areas;
reason; decision/domain/outcome; source-grounded observations) and orientation
proposals. A changed understanding, a provisional observation, and reviewed-
discarded consultation are distinct outcomes. Invalid, mismatched, competing or
unjustified outputs fail closed. `awake` is the sole semantic proposal path;
top-level compatibility candidates are advertised as empty and runtime-checked.
Legacy fixtures/callers without this explicit protocol retain their old shape;
there is no third user-selectable conversation mode.

The existing provider route, meaning operations and steward apply valid changes
on that turn without waiting for the refresh flag. Fictional temporary activity
can establish SHORT/focus without becoming a real-world personal FACT. Grounded
unfinished commitments have explicit add/resolve operations and source metadata;
a topic change alone does not resolve a promise or prove permanent abandonment.
Old context files remain readable; optional orientation evidence extends the
existing Living Mind metadata without migration or a separate store.

All normal turns explicitly evaluate meaning. Mandatory checkpoint flags occur
before the existing three-exchange/size window compacts, at twenty-turn intervals,
and at Sleep, handoff and explicit review. Ordinary checkpoints share the normal
provider call. Boundary/explicit reviews can make one bounded additional call;
they do not append synthetic control dialogue to conversation or journals. Their
control instruction is never accepted as source evidence. The selected provider
and existing budget meter expose those calls. Structured-output bounds remain
2,000 tokens normally and 3,000 at checkpoints; no paid probe was made.

Checkpoint packets include up to twenty completed, same-scope exchanges plus
pending evidence. Failure/defer preserves the exact packet for retry, including
its raw window; it never clears the history to manufacture a successful review.
Successful source validation permits compaction, not factual certainty. The old
twelve-exchange temporary hard stop is removed. There are explicit packet/source
capacity limits and a 2 MiB session-record cap; exceeding them reports a blocker
and retains evidence rather than silently truncating it. Original temporary
exchanges remain session-local for the existing explicit preservation choices.

Observations/hypotheses are scoped session-local review artifacts with uncertainty,
source chains and fresh version IDs. New explanations refer to earlier versions;
discard/supersession is labeled rather than hindsight rewriting. Current requests
receive only that scope's bounded provisional observation history. Those artifacts
are not automatically written as canonical memory or copied wholesale into Drive
review receipts. Eligible semantic updates still use the same authorized durable
checkpoint/conditional-write/readback path. A durable review-write failure keeps a
pending operation and blocks unsafe replacement; retry reuses the model result.
Explicitly discarding a completed but uncommitted interpretation is a distinct
user action, not an automatic rollback or Drive deletion.

## Inspector and reset diagnostics

In ordinary Chat, expand **Living Mind — working state** directly below the two
conversation modes. It reads the actual session, not a static Drive template:
scope, mode, committed/working versions, LONG/SHORT, orientation, last review,
provisional observations, pending sources, verified commits and reset diagnostics.
**Review pending evidence / retry** is an explicit provider action; ordinary
inspection makes no call and writes nothing. The full private trace remains in
Menu → Living Mind → State evolution. Trace outcomes no longer conflate no new
personal FACT, unchanged LONG/SHORT and no observation worth carrying forward.

Requests/traces carry conversation ID, runtime session ID, turn sequence and
reset reason. New conversation constructs a fresh session; successful Google
reauthorization preserves the current working session instead of silently
reconstructing it. Before-unload warns about unreviewed or uncommitted local work.
Ignoring the warning, closing/killing a browser, or losing a device can still lose
unpersisted temporary material; no private browser-local durable archive was added.

## Integrated engine and permission boundary

The existing scoped context reader, typed meaning operations, versioned current
package, source validation and conditional Memory Bridge writer are reused.
There is no second project-memory engine or separate memory store.

- JUST CHATTING: load authorized memory; evolve the working five-section package,
  attributed belief proposals, affect and orientation locally. No checkout,
  journal, archival or context write. Explicit opt-out overrides model proposals.
- REMEMBER WITH ME: eligible meaningful updates persist through journal-backed
  checkpoints and readback verification. No-change is visible and valid. Explicit
  Remember/Recall remains available as before.
- Temporary→durable presents four explicit choices: understanding, original
  exchanges, both, neither. The dialog exposes committed/working understanding.
  Temporary raw history is cleared from future working prompts at transition;
  it is not silently included in a subsequent durable snapshot.
- Durable→temporary releases the checkout and stops future persistence without
  erasing current durable memory.
- Sleep/end: meaningful temporary differences offer Save understanding only or
  Let it go. No-change ends without a prompt. Pending durable checkpoints must
  verify before handoff. The pre-existing reflective Sleep remains a separate
  explicit action, not the first opportunity to remember.

Understanding-only uses the **same conditional current-state writer**, authorized
by a locally minted explicit-consent receipt. Optional `memoryBridge.stateReceipt`
contains an authority ID, timestamp and source hashes/IDs, not raw source text.
`journalReference: null` is valid only with this strictly validated receipt; older
journal-backed metadata remains readable. Current LONG/SHORT/RECENT and attributed
review material are saved; `livingMind.conversation` is empty. Existing journal
links are preserved. Unsaved checkpoint retries reuse the operation/receipt and do
not call the model. A source hash proves binding, not human semantic approval or
availability of deliberately unarchived original text. Do not reconstruct missing
sources or claim they are archived. Original raw content remains available only
when the user explicitly chose archival or was already authorized for retention.

Inspect and Resume load committed understanding without acquiring a checkout.
Conflicts open the visible handoff controls. Take over requires an explicit
confirmation and rejects stale writers; it cannot merge another tab's unsaved
work. Authorization no longer silently trashes expired journal files; readers
still exclude expired provisional material. No unrelated Drive file cleanup.

Each temporary preservation batch is bounded to twelve eligible exchanges. At
that boundary the UI asks the user to resolve the session before another send;
it does not silently evict provenance or promote the batch. Browser closure loses
uncommitted temporary work by design. Durable replies already verified in Drive
do not depend on graceful closure. Full reflective services and general canonical
FACT/INSIGHT reconciliation remain unfinished; attributed working candidates
must not be represented as independently established canonical facts.
